# Marionetta

Marionetta interattiva in HTML/SVG puro, senza dipendenze (solo il font Raleway da Google Fonts).

- Trascina la croce o il busto per muovere la marionetta
- Afferra mani e gambe per farle muovere
- Pulsanti: Saluta, Balla, Cammina, Riposo

## Logo GiN
Sulla maglietta c'è una scritta "GiN APS" di default. Per usare il logo vero, salva un file `logo.png`
(meglio con sfondo trasparente) nella stessa cartella di `index.html`: viene usato in automatico.

## Pubblicare su GitHub Pages
1. Crea un repository e carica questi file (`index.html`, `photo.png`, `.nojekyll`, opzionale `logo.png`)
2. Settings → Pages → Source: `main` / root
3. Il sito sarà su `https://<utente>.github.io/<repo>/`

Nota: `photo.png` è una foto di una persona reale: se il repository è pubblico, lo sarà anche la foto.
